# Day 15 — Tile Map (Static World)

## Goal
Replace hardcoded walls with data-driven level layout.

## Learn
- Grid-based worlds
- Tile size vs world coordinates
- Generating colliders from data

## Tasks
- Define a 2D tile array (int grid)
- Choose a fixed tile size (e.g. 32×32)
- Convert solid tiles into wall AABBs
- Render tiles as simple colored rectangles

## Deliverable
- Level defined by data, not hardcoded rectangles
